# Day 40 - Linux Fundamentals

## What is Linux?

Linux is an open-source operating system widely used on servers, cloud platforms, and cybersecurity systems.

## Why Learn Linux?

- Most servers run Linux.
- Many cybersecurity tools are designed for Linux.
- It is essential for SOC analysts and penetration testers.

## Important Directories

/      -> Root directory
/home  -> User home directories
/root  -> Root user's home
/etc   -> Configuration files
/bin   -> Essential commands
/tmp   -> Temporary files
/var   -> Logs and changing data

## Basic Commands

pwd     -> Show current directory
ls      -> List files and folders
whoami  -> Show current user
clear   -> Clear terminal

## Why It Matters

Linux knowledge is essential for investigating servers, analyzing logs, and using many cybersecurity tools.
