# Day 25 - Open Ports and Services

## What is an Open Port?

An open port is a port where a service is waiting for connections.

## Analogy

Computer = Building
Port = Door

## Common Ports

80  - HTTP
443 - HTTPS
53  - DNS
22  - SSH
25  - SMTP

## Why Open Ports Matter

Open ports expose services to the network.

Unnecessary open ports increase security risks.

## Command Used

netstat -an
