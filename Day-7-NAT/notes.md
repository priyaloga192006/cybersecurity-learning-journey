# Day 7 - NAT

## Full Form

Network Address Translation

## Purpose

Allows multiple devices to share one public IP address.

## Performed By

Router

## Translation

Private IP ↔ Public IP

## Example

Laptop:
192.168.1.10

Router Public IP:
49.xxx.xxx.xxx

## Why NAT is Important

Conserves public IPv4 addresses and allows many devices to access the internet using a single public IP.
