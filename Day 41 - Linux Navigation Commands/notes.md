# Day 41 - Linux Navigation Commands

## pwd
Shows the current working directory.

## ls
Lists files and directories.

## cd
Changes the current directory.

## cd ..
Moves one directory back.

## cd ~
Returns to the user's home directory.

## cd /
Moves to the root directory.

## ls -l
Shows detailed file information.

## ls -a
Displays hidden files.

## history
Shows previously executed commands.

## Why It Matters

Linux navigation is essential for finding files, examining logs, and using cybersecurity tools effectively.
