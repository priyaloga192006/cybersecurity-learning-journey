# Day 23 - Vulnerabilities and Patching

## Vulnerability

A weakness in a system that can be exploited.

## Patch

A fix released by a software vendor.

## Update

Installing the latest version of software.

## Why Updates Matter

Updates often contain security fixes.

Without updates:
- Systems remain vulnerable
- Attackers may exploit known weaknesses

## Defensive Security Practices

- Apply patches
- Update software regularly
- Remove outdated software
- Monitor vulnerabilities
