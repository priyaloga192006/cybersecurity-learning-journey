# Day 36 - Windows Processes and Services

## What is a Process?

A process is a program that is currently running in memory.

## What is a Service?

A service is a background program that usually starts automatically with Windows.

## Process vs Service

Process:
- Started by the user
- May have a visible window

Service:
- Runs in the background
- Usually starts automatically

## Task Manager

Shortcut:
Ctrl + Shift + Esc

Task Manager shows:
- Running processes
- CPU usage
- Memory usage
- Disk usage
- Network usage

## Process ID (PID)

Each running process has a unique Process ID used to identify it.

## Why It Matters

Cybersecurity professionals monitor processes and services to detect malware, investigate suspicious activity, and respond to incidents.
