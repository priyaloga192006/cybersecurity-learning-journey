# Day 8 - Firewall

## What is a Firewall?

A firewall is a security system that monitors and controls network traffic.

## Purpose

- Allow trusted traffic
- Block unwanted traffic

## Types

### Host Firewall
Example:
Windows Defender Firewall

### Network Firewall
Example:
Router Firewall

## Practical Command

netsh advfirewall show allprofiles

## Observation

The firewall can be ON or OFF and uses rules to allow or block traffic.
