# Day 16 - Multi-Factor Authentication

## Full Form

Multi-Factor Authentication

## Purpose

Adds extra security by requiring more than one authentication factor.

## Authentication Factors

### Something You Know
- Password
- PIN

### Something You Have
- Phone
- OTP
- Authenticator App

### Something You Are
- Fingerprint
- Face Recognition

## Example

Password + OTP

## Benefit

Even if a password is stolen, attackers still need the second factor.
