# Day 35 - Windows Users and Permissions

## What is a User?

A user account allows a person to use a computer with their own files and settings.

## Common Groups

- Administrators
- Users
- Guests

## Administrator

Can:
- Install software
- Manage users
- Change system settings

## Standard User

Can:
- Run applications
- Create personal files

Cannot:
- Perform most administrative tasks

## File Permissions

- Read
- Write
- Execute
- Delete

## Why Permissions Matter

Permissions protect sensitive files and reduce security risks.

## Principle of Least Privilege

Users should receive only the permissions they need to perform their jobs.
