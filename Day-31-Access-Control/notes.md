# Day 31 - Access Control

## What is Access Control?

Access Control determines who can access a resource and what actions they are allowed to perform.

## Principle of Least Privilege (PoLP)

Users should receive only the minimum permissions required to perform their jobs.

## Benefits

- Improves security
- Limits attacker damage
- Protects sensitive data
- Reduces accidental mistakes

## User Types

Administrator:
- Full system control

Standard User:
- Limited permissions

## Example

Intern:
- Read documents
- Access email

Not Allowed:
- Install software
- Delete databases
- Create administrator accounts
