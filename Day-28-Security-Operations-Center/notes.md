# Day 28 - Security Operations Center (SOC)

## What is a SOC?

A Security Operations Center is a team that monitors, detects, investigates, and responds to security incidents.

## SOC Responsibilities

- Monitoring
- Detection
- Investigation
- Response

## SOC Workflow

Logs
↓
Monitoring
↓
Alert
↓
Investigation
↓
Response

## SOC Analyst Tasks

- Analyze alerts
- Review logs
- Investigate incidents
- Escalate threats
