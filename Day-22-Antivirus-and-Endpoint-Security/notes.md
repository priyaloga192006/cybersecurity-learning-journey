# Day 22 - Antivirus and Endpoint Security

## What is Antivirus?

Software that detects, blocks, and removes malware.

## What is an Endpoint?

Any device connected to a network.

Examples:
- Laptop
- Desktop
- Mobile Phone
- Server

## What is Endpoint Security?

Protecting endpoint devices from cyber threats.

## Antivirus Detection Methods

### Signature Detection
Matches known malware patterns.

### Behavior Detection
Detects suspicious behavior such as mass file encryption.

## Quarantine

Isolates suspicious files so they cannot execute.

## False Positive

A legitimate file incorrectly detected as malware.

## Important Note

Antivirus alone is not enough.

Additional protections:
- MFA
- Backups
- Updates
- Monitoring
- User Awareness
