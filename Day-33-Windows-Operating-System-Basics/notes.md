# Day 33 - Windows Operating System Basics

## What is an Operating System?

Software that manages computer hardware and provides services for applications.

## Examples

- Windows
- Linux
- macOS

## Main Windows Components

- Desktop
- File Explorer
- Taskbar
- Control Panel
- Settings

## User Types

### Administrator
- Full system control

### Standard User
- Limited permissions

## File System

Windows uses NTFS.

## Why Learn Windows for Cybersecurity?

Understanding Windows helps security professionals investigate incidents, analyze logs, manage users, and protect systems.
