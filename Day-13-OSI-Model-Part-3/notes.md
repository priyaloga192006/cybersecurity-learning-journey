# Day 13 - OSI Model Part 3

## Layer 5 - Session

Creates, manages and ends communication sessions.

Examples:
- Login
- Logout

## Layer 6 - Presentation

Responsible for:
- Encryption
- Compression
- Data Formatting

Example:
HTTPS

## Layer 7 - Application

Applications used by users.

Examples:
- Chrome
- WhatsApp
- Gmail
- YouTube
