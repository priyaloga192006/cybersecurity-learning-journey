# Day 12 - OSI Model Part 2

## Layer 3 - Network Layer

Responsible for routing data between networks.

Examples:
- IP Address
- Router
- IPv4
- IPv6
- NAT

## Layer 4 - Transport Layer

Responsible for end-to-end delivery of data.

Protocols:
- TCP
- UDP

Ports:
- 80 (HTTP)
- 443 (HTTPS)

netstat -an
