# Day 34 - Windows File System & NTFS

## What is a File System?

A file system stores, organizes, and manages files on a storage device.

## Windows File System

Windows primarily uses NTFS (New Technology File System).

## Features of NTFS

- File permissions
- Encryption
- Compression
- Reliability
- Large file support

## Important Folders

### C:\Windows
Contains operating system files.

### C:\Program Files
Contains installed applications.

### C:\Users
Contains user profiles and personal folders.

### Downloads
Common location for downloaded files and a frequent place to investigate suspicious files.

## Why It Matters in Cybersecurity

Security analysts investigate file locations, ownership, and modifications during incident response.
