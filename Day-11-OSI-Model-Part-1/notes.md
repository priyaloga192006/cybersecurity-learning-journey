# Day 11 - OSI Model Part 1

## What is the OSI Model?

A networking model that divides communication into 7 layers.

## Layers

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

## Layer 1 - Physical

Responsible for transmitting bits through cables and wireless signals.

Examples:
- Ethernet Cable
- Fiber Cable
- Wi-Fi Signals

## Layer 2 - Data Link

Responsible for local communication using MAC addresses.

Examples:
- MAC Address
- Switch
