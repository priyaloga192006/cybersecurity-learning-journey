# Day 42 - Linux File Management

## mkdir
Creates a new directory.

## touch
Creates an empty file.

## cp
Copies files or directories.

## mv
Moves or renames files.

## rm
Deletes a file.

## rmdir
Deletes an empty directory.

## rm -r
Deletes a directory and all its contents.

## cat
Displays the contents of a file.

## echo
Prints text or writes text into a file.

## nano
Simple command-line text editor.

## Why It Matters

File management is essential for organizing evidence, reviewing logs, handling scripts, and managing files during cybersecurity investigations.
