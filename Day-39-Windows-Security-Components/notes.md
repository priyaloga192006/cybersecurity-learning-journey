# Day 39 - Windows Security Components

## Event Viewer
- Stores system logs.
- Records application, security, and system events.
- Used during investigations.

## Windows Registry
- Database storing Windows and application settings.
- Can be modified by malware for persistence.
- Open with: regedit

## Windows Defender
- Built-in antivirus.
- Provides real-time protection.
- Supports Quick, Full, and Custom scans.
- Quarantines detected threats.

## Windows Firewall (Advanced)
- Filters incoming and outgoing network traffic.
- Uses Inbound and Outbound rules.
- Profiles:
  - Domain
  - Private
  - Public

## Why These Matter

Together they help detect, prevent, record, and investigate security incidents on Windows systems.
