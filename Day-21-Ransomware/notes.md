# Day 21 - Ransomware

## What is Ransomware?

A type of malware that encrypts files and demands payment.

## Typical Attack Flow

Phishing Email
↓
Malware Download
↓
Ransomware Execution
↓
File Encryption
↓
Ransom Note

## Risks

- Data loss
- Business disruption
- Financial loss

## Protection

- Backups
- MFA
- Security Awareness
- Software Updates
- Monitoring

## Defensive Response

1. Isolate infected system
2. Stop spread
3. Analyze logs
4. Restore backups
