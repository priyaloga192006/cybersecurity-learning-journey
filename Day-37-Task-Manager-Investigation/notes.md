# Day 37 - Task Manager & Process Investigation

## What is Task Manager?

Task Manager is a Windows utility used to monitor running applications, processes, services, and system performance.

## Important Tabs

### Processes
Shows running applications and resource usage.

### Performance
Displays CPU, Memory, Disk, Network, and GPU usage.

### Startup Apps
Shows applications that start automatically with Windows.

### Details
Displays detailed process information including Process IDs (PIDs).

### Services
Shows the status of Windows services.

## Why It Matters in Cybersecurity

Task Manager helps identify suspicious processes, investigate high resource usage, and supports incident response.
