# Day 1 - Network Basics

## What is a Network?

A network is a group of connected devices that can communicate and share data.

Example:
Laptop ↔ Phone ↔ Router

## What is the Internet?

The internet is a network of networks connected worldwide.

## What is Wi-Fi?

Wi-Fi is a wireless technology used to connect devices to a network.

## What is a Router?

A router directs network traffic between devices and the internet.

## What is an ISP?

ISP stands for Internet Service Provider.

Examples:
- Jio
- Airtel
- BSNL

## What is an IP Address?

An IP address is a unique address assigned to a device on a network.

Example:
192.168.1.10

## Public IP vs Private IP

Public IP:
Used on the internet.

Private IP:
Used inside local networks.

## IPv4 vs IPv6

IPv4:
192.168.1.10

IPv6:
2404:6800:4002:804::200e

## Default Gateway

The router's IP address used to reach other networks.
