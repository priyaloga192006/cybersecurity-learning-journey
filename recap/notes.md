Important directories:

Directory	Meaning	Purpose
/	Root	Starting point of the filesystem
/home	Home	Stores users' personal files
/root	Root User Home	Administrator's home directory
/etc	Et Cetera	Configuration files
/bin	Binary	Essential commands
/usr	User System Resources	Applications and libraries
/var	Variable	Logs, cache, databases
/tmp	Temporary	Temporary files
/dev	Devices	Hardware device files
/proc	Process	Running process information
