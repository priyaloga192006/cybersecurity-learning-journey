# Day 4 - Ports, HTTP and HTTPS

## Port

A logical communication endpoint.

Example:

IP Address = Building Address

Port = Room Number

## HTTP

Full Form:
HyperText Transfer Protocol

Port:
80

## HTTPS

Full Form:
HyperText Transfer Protocol Secure

Port:
443

## Why HTTPS?

HTTPS encrypts communication between browser and website.

## Important

DNS finds the device.

IP identifies the device.

Port identifies the application.
