# Day 32 - Access Control Models

## What is an Access Control Model?

A set of rules that determines who can access resources and what actions they can perform.

## Types

### Role-Based Access Control (RBAC)
Access is based on the user's role.

### Discretionary Access Control (DAC)
The owner of the resource decides who can access it.

### Mandatory Access Control (MAC)
Access is controlled by security policies and security clearance.

## Why It Matters

- Protects sensitive information
- Supports the Principle of Least Privilege
- Reduces the impact of compromised accounts
