# Day 5 - MAC Address

## Full Form

Media Access Control

## What is a MAC Address?

A MAC address is a unique hardware address assigned to a network adapter.

## Purpose

Used to identify devices within a local network.

## Example

00-1A-2B-3C-4D-5E

## Difference Between IP and MAC

IP Address:
Logical address that can change.

MAC Address:
Hardware address that is usually fixed.
