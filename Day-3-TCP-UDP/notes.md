# Day 3 - TCP vs UDP

## TCP

Full Form:
Transmission Control Protocol

Features:
- Reliable
- Ordered Delivery
- Retransmits Lost Packets

Examples:
- Banking
- Email
- Software Downloads

## UDP

Full Form:
User Datagram Protocol

Features:
- Fast
- Low Delay
- No Delivery Guarantee

Examples:
- Gaming
- Video Calls
- Live Streaming

## Key Difference

TCP = Reliability

UDP = Speed and Low Delay
